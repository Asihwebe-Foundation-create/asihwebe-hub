# Asihwebe Foundation website

## Scope
- Build a complete, responsive institutional website with Asihwebe as the primary brand.
- Use the supplied logo where suitable and generate authentic-looking South African community and enterprise imagery.
- Create separate pages for Home, About Us, Our Programmes, TRDEA, Partnerships, Impact, Contact, Support Our Work, Privacy Policy, and Website Terms.
- Include leadership and future governance placeholders without inventing biographies, qualifications, photographs, partner logos, or impact figures.

## Experience and content
- Establish a warm, credible visual system using deep navy, warm gold/orange, white, and light neutral backgrounds.
- Build reusable navigation, footer, page hero, programme cards, impact metrics, calls to action, forms, testimonial placeholders, and partner-logo placeholders.
- Keep the home page focused on mission, programmes, TRDEA, approach, partnerships, impact readiness, distinctive strengths, support, and involvement.
- Present TRDEA as a scalable flagship programme with the supplied eight-step pathway.
- Keep Phakama Marketplace secondary and only reference it as a possible technology or marketplace-access partner pending approved wording.

## Functional flows
- Enable Lovable Cloud for secure storage of contact and involvement enquiries.
- Validate forms in the browser and on the server, show accessible success and error states, and avoid exposing submitted details.
- Build the donation selector as an explicitly labelled demonstration that never claims to process payment.
- Make editable content data-driven so programmes, leaders, metrics, and future partners can be updated without restructuring pages.

## Quality checks
- Add unique page titles, descriptions, social metadata, and semantic page structure.
- Verify navigation, mobile menu, forms, donation demonstration, and key page layouts on desktop and mobile.
- Confirm that no unverified statistics, biographies, photographs, partner logos, or payment claims appear.

## Technical details
- Use TanStack Start routes and shared React components with Tailwind v4 semantic design tokens.
- Store enquiries in a Cloud table protected by row-level access rules; submissions use validated server functions.
- Use optimized project-managed image assets and Lucide icons.
